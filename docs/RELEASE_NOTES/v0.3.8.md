# Uartix+ v0.3.8

工业 Modbus 全链路补齐：从「抓包看得懂」到「没有硬件也能测」。RTU / TCP 整簇预设开箱可用，寄存器与线圈自动展开成可画曲线的通道；新增 **Modbus 工作台** 面板，本机可当模拟从站应答总线，也可当主站按周期轮询并把值直接写成变量。

## Modbus 解码：一条模板吃下整条总线

- **逐字节位掩码匹配**：帧头与识别位都支持 `??`（整字节通配）、`A?` / `?5`（半字节）、`80&F0`（显式掩码）。从站地址每帧都变？写 `?? 03` 一条模板覆盖全总线；异常响应用 bit7 掩码，一条覆盖所有功能码的异常
- **寄存器区自动展开**：读响应不再是一坨 `00 0A 01 F4`，直接出 `寄存器1..N` 通道，可选 16/32 位与四种字序（ABCD / DCBA / CDAB / BADC）
- **线圈区按位展开**：FC01 / FC02 的响应一位一通道（`线圈1..N`，低位在前），可直接画曲线、绑变量、进表格
- **位数换算**：FC01 / FC02 长度域记的是位数不是字节数，新增 `lengthScale` 倍率机制（配 0.125）正确定帧
- **Modbus TCP 支持**：MBAP 头定帧，并靠长度域奇偶精确区分主从方向——嗅探 502 端口时上位机与 PLC 的对话不再互相误判
- **值标签（异常码会说话）**：字段可配 `1=非法功能码; 2=非法数据地址`，表格 / 导出 / 帧画布 / 图例 / AI 上下文统一显示「数字 文字」，数值通道与脚本仍拿原始数字。这是通用枚举注解能力的第一例
- **抗错位增强**：坏帧不再吞帧头（保留候选后缀重扫）、通配帧首时关闭帧中途重锚定（不再把好帧拦腰截断）、主从共用功能码产生的噪声坏帧自动去噪

## Modbus 工作台：没有 485 设备也能跑通

- **模拟从站**：本机当从站应答总线请求。线圈 / 离散输入 / 保持寄存器 / 输入寄存器四张可编辑数据表，可设从站地址或「应答所有地址」当多从站
- **故障注入**：不回应答（复现主站超时）、一律回指定异常码、隔一次回一次异常，外加应答延时模拟慢速从站——调试主站程序时最需要的就是"让设备坏一下"
- **主站轮询表**：每行「从站 + 功能码 + 起始地址 + 数量 + 周期 + 变量名 + 元素序号 + 倍率」，按周期发读请求，**响应解析后直接写成变量**，不用再配协议模板
- **半双工安全**：同一时刻只允许一条在途请求，1 秒无应答记超时并放行下一条；从站与轮询互斥启动（自己问自己答只会得出"设备健康"的假象）
- **关掉面板仍在运行**，串口工具栏出现绿色徽标提示并可一键回到工作台
- **指令工厂补齐发送侧**：新增 FC15 / FC16 写多点、新增 Modbus TCP 编解码器（MBAP 自动组帧、事务号可自增），起始地址可直接抄 `40001` 这类手册编号自动换算

## AI 助手

- **知识同步**：识别位、位掩码、长度倍率、四种字序、寄存器 / 线圈数组、值标签全部写入协议规范，AI 生成的模板现在用得上这些新能力
- **不再重造轮子**：判定为维特 WIT / 匿名 V7 / Modbus RTU·TCP / NMEA 0183 / JustFloat 时，AI 直接引导你一键套用内置预设
- **会操作工作台**：新增 `modbus` 动作（共 28 个白名单动作）——"把 40003 设成 1234"、"每 500ms 读 1 号从站 10 个寄存器"、"让它别应答试试"都能一句话完成（需脚本高权限，因为会主动占用总线）
