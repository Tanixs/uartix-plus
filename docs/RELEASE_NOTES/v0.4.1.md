# Uartix+ v0.4.1

一版三个新面板：**3D 轨迹 + 校准全家桶**（椭球九参数/六面向导/补偿预览，校准完直接抄进固件）、**自动编排器**（12 类事件 × 23 类块的 ECA 自动化引擎，内置 **PID 继电反馈自整定**）、**虚拟设备工坊**（让软件扮演一台有温漂丢帧脾气的真设备，还能 UDP/TCP/串口对外收发）——**没有硬件，从连接到 PID 调参的整条工作流都能跑通**。外加第 5 轮实锤修好的频谱分析、9 步交互式教学、Operator/哨兵/序列器一轮状态闭环大修。

## 3D 轨迹面板：把三个通道画成空间轨迹

- 航迹 / 相图 / 姿态积分：双层 LOD 十万点长跑不卡，大坐标（经纬度 120.xxx）自动重锚不丢精度；键盘飞行（WASD/QE）、缩放到光标、跟随模式、底部时间条历史回看与回放联动
- **椭球校准**：绑原始三轴 → 翻滚采样 → 九参数最小二乘（硬磁偏置 + 软磁对称校正矩阵），残差着色看质量、原始/校正后一键对比、在线补偿预览（转一转，曲线贴 1.0 线 = 校准有效）；结果复制 JSON / C 数组直接进固件
- **加计六面向导**：六个面各静置 2 秒，σ 自动拒绝晃动，解出 offset/gain 与 CV 质量指标
- 三轴来自不同帧、不同采样率？配对模式（插值/最近点 + 容差）+ 逐轴独立缩放，不再被压成直角折线

## 自动编排器：会自己动的自动化

测试序列器的块流 × 触发器的事件驱动融合成 ECA 编排：组头事件槽挂 12 类事件（帧命中/坏帧/新帧型/阈值/通道变化/定时器/会话/哨兵/变量变更/自定义事件/通信静默）自动触发，组内 23 类块线性执行（含设控件、写 Modbus、截曲线图、导 CSV 等自动化工具箱）。FIFO 队列、冷却、三重熔断兜底；表达式支持 abs/clamp/if/len/fmt 等白名单函数与 `now`。

- **PID 继电反馈整定**（内置模板）：阈值事件记穿越 → 攒 6 个摆动周期 → 自动算 Ku 并按 Ziegler-Nichols 出 Kp/Ti/Td 回发设备——串口工具圈少见的自动调参，配合虚拟设备「温控炉」零硬件练手
- 「从模板新建」另有报警通知 / 看门狗 / 定时轮询 / 收发握手四套，导入默认停用待检查
- 对 AI 说一句话即可搭出「事件→块树」（eventAdd/blockAdd），缺什么参数如实回传提示

## 虚拟设备工坊：没有硬件的全链路

用 JSON 规格定义一台虚拟设备：六种信号模型（含一阶惯性对象）+ 噪声/温漂 + 丢帧/卡死/毛刺 + 帧格式 + 命令应答（支持 `SET DUTY 45` 数值捕获）。启动自动配套协议模板，运行中像真设备一样**对外收发**：UDP（广播/多目标/监听收令）、TCP 客户端/服务端、独占串口。内置温控炉与虚拟 MPU6050；对 AI 说「模拟一个有温漂偶尔丢帧的 MPU6050」即生成入库。**双机教学**：A 机启动设备开 UDP 发射，B 机导「虚拟设备·温控炉」预设接收——同一条曲线，两台电脑。

## 频谱分析：这回是真根因

「不出图」修了四轮没修中，第五轮读码实锤：容器 ref 出生就没绑上 DOM，uPlot 实例从未创建——一处修复三路全通。同时把「数据不够却虚报高采样率」改为**诚实降点**：自动降到实际数据支持的 FFT 点数并在摘要行提示。空态引导卡在面板里直选协议字段建通道，失败原因显式显示。

## 教学引导：新手 2 分钟走通主流程

快速入门页顶部「启动交互式教学」——9 步聚光灯分步引导（连接→演示源→预设→帧画布→曲线→控制→AI），第一次启动自动弹出欢迎卡，帮助里随时重看。

## 也修了很多真的

- **Operator 部署包**：只读边界下沉 store 层（AI/MCP 同等受约束，编排器可运行、3D 校准放行）；空包拒绝生成；activate 事务化失败回滚；3D 面板设置随包
- **哨兵**：浮球拖完不误弹面板；桌面挂件纳入监测门控不再假报离线
- **序列器**：运行结果树实时心跳刷新；每个套件保留最近结果切走不丢
- **编排器**：等帧超时填 0 = 真无限等；折叠组不再误杀在跑的实例；事件块配置不完整挂警示徽标
- **3D**：显卡抖动丢 WebGL 上下文后重建**保留校准采样**——几分钟的采样不再全灭
- 状态栏新增「演示源」「虚拟设备」徽标；「+ 面板」五组分块 + 最近使用；字符图标清零与语义色对比度逐主题达标
