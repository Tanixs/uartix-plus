# Uartix+ v0.3.9

一版六个大能力：**AI 协议考古学家**（校验爆破+考古报告）、**MCP 服务器**（Claude/Cursor 直连你的串口）、**频谱分析面板**、**Operator 只读部署包**、**哨兵 × AI 根因诊断**、**视觉测试序列器**（含 CI 无硬件跑测）。外加 BLE 自动重连、Modbus/XMODEM 一轮清账。

## 测试序列器：拖积木组出自动化测试

- **视觉编排**：步骤树拖拽排序（发命令/等待帧/断言/循环/组），断言失败详情直达字节级；帧触发自动运行
- **HTML 报告**：自包含单文件（内联样式、分组折叠、超限截断提示），桌面导出与 CLI 共用同一生成器
- **进 CI**：`seq-cli --loopback`（内置回环设备，可注入延时/坏帧）+ `--junit` 输出，GitHub Actions 无硬件全流程跑断言；新增 ASCII 字符直发（含 `\r` `\n` `\xNN` 转义）

## AI 协议考古学家：从字节堆到协议结构

- **校验爆破**：按帧长切行，穷举 8 类算法 × 覆盖段 × 位置 × 端序（sum8/xor8/sumadd/sum16/CRC16-Modbus/CCITT/X25/CRC32），全帧通过标「实锤」、≥90% 标「疑似」，命中一键按此建协议模板
- **序列/轮询分析**：帧头签名间距语义（周期帧/事件帧）、主从轮询循环检测（A→B→A→B + 周期中位数）
- **AI 考古报告**：确定性证据链 E1..En（帧长/帧头/恒定列/高熵域/爆破实锤/帧型/轮询），AI 只许引用证据编号推理，禁编造数值；对 AI 说「分析一下这协议什么结构」即出报告

## MCP 服务器：AI IDE 反向集成

- 本地 MCP stdio 服务，**Claude Desktop / Cursor 直接读写串口数据**：状态/字段/帧流/绘图统计/报警/发送/跑动作/跑序列 8 个工具
- 零依赖 CLI（`npm run build:mcp` 一条命令出产物），发现文件自动定位运行中的 app，端口可变不破坏 IDE 配置
- 安全默认：首行 token 握手、单授权客户端、远程发送与高权限动作独立开关、调用审计列表
- `get_frames` 支持 `beforeSeq` 游标分页，环形缓冲扩到 **1024 帧**，IDE 可翻页取深度历史

## 频谱分析面板

- FFT / 直方图双模式：Hann/矩形窗、线性/dB、1024~32768 点、Top3 主峰与均值/σ 摘要
- 与 2D 曲线共享通道（加一次通道到处可用）；重算 800ms 节流 + 数据签名，后台 tab 零开销
- 2D 曲线跟随刷新改 rAF 驱动，最新数据丝滑右推（根治 8.3fps 固定平移的跳变感）

## Operator 部署包：调好的工作区一键发行

- 设置 → 数据 生成 `.uopk`：协议模板/控制页/命令库/布局四部件任选，外观设置白名单随包；**AI 密钥等本机私有项绝不进包**
- 双击文件导入（已注册文件关联 + 单实例聚焦），只读运行：能连设备/发命令/看数据，改配置一律拦截；横幅一目了然，退出即恢复可编辑

## 哨兵 × AI 根因诊断

- **哨兵监测**：通道突变/静默/错误率自动检测，健康度评分、报警卡、桌面挂件、合成提示音（不关面板就不监测，绝不后台偷跑）
- **AI 诊断**：一键把连接状态/近期报警/异常通道评分等结构化证据发给 AI 出根因分析；crit 报警可自动触发（默认关，1~60 分钟冷却），直写 AI 会话不弹窗不抢焦点

## BLE 更可靠

- 意外断开自动重连（3s 重试 ×3，复用常驻 Adapter 设备缓存，无需重新扫描）
- 非标准透传设备可**手动指定写/收特征 UUID**（属性校验 + 用户可读错误），连接中改选立即断开重连生效

## Modbus / 传输清账

- Modbus 从站与轮询互斥双向提示；主站轮询表新增**趋势火花线**（行内 mini 曲线，600 点环形）
- XMODEM 支持 **PC 作接收方**（设备→PC）与 **YMODEM-G**；录制与传输互斥
- AI 图片 IndexedDB 容量上限可配置；控制页/图传一轮易用性修复

## 其他

- i18n 扫尾：频谱/2D 曲线/帮助结构等深处文案补齐双语（**帮助长正文保持中文**）
