# Uartix+ v0.3.7

协议考古再进化：结构发现面板学会「协议簇」——混发多种帧型的未知协议（如 WIT 陀螺仪）一次看清、勾选即建整套模板。同时带来 UI 体系升级、AI 助手知识刷新与一批性能红利。

## 结构发现：协议簇（本版本核心）

- **簇发现算法**：对候选帧头做「帧头家族 + 帧间距直方图」分析，同一帧头下的多种帧型与各自帧长一次识别，不再被混合流量摊薄
- **参数可调**：显著度阈值 / 帧长上限 / 分析窗口，采样缓冲扩至 256KB，统计与渲染严格同一冻结快照
- **人来定种**：帧头与长度字段统计打平（相位二义）时，恒定段每行「簇分析」按钮把选择权交给你
- **勾选即建档**：簇卡片勾选帧型 → 一键批量生成协议模板；模板面板可对已有簇「＋添加帧型」继续补全

## AI 助手

- **服务预设刷新到 2026-09 现役模型**：GPT-5.6-Sol、DeepSeek-V4-Pro、新增智谱 GLM-5.3 预设、Qwen3.8-Flash、Claude Sonnet 5、Ollama Gemma4；已停服的旧模型名（如 deepseek-chat）自动迁移，不再撞墙
- **知识库同步**：AI 现在知道五类数据接口（串口/TCP 客户端/TCP 服务端/UDP/蓝牙 BLE）、结构发现与协议簇、会话录制回放、XMODEM/YMODEM 文件传输——问它"支持什么"不会再答漏
- **会造遥控卡**：摇杆（%x/%y 坐标模板）、四向键盘遥控、单键遥控三类卡片可由 AI 直接生成
- **生成主题更稳**：内置按钮文字对比度硬规则与设计令牌规范，亮色主题不再配白字

## 界面与体验

- 设计令牌体系 + 跟随系统的减少动效降级；全部数值位 tabular-nums，实时读数不再抖动
- 新增 Okabe-Ito 色觉友好曲线色板（设置 → 数据/诊断 切换）；修复三套主题按钮文字可读性
- 面板页签拖拽回归修复（可再拖入任意分组）；控制台时间戳贴左

## 性能与质量

- release 编译调优（LTO/单 CGU/strip），Excel 导出移入 Rust（并移除含 CVE 的旧依赖）
- 全库 ESLint 0 error、64 项前端单测、无障碍与主题对比度 CI 检查——重构与迭代有护栏
