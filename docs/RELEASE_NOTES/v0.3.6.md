# Uartix+ v0.3.6

AI 助手大版本：从「聊天问答」进化为「能创造、能执行、能感知」的应用内引擎；同时带来帧画布易用性补全与深度面板中英双语。

## AI 助手（本版本核心）

- **十种创作块**：对话即可生成并一键安装——协议模板、控制卡片（含自定义沙箱卡片）、命令库、指令工厂协议、主题 / 全局样式、可停靠面板、沙箱小部件、无边框挂件、直接执行动作（uartix-action）、高权限脚本
- **说出来即发生**：操作类诉求（打开面板、切布局、连串口…）由 AI 直接执行，27 个白名单动作，破坏性动作红标 + 人工确认
- **uartix API 桥**：所有沙箱组件自动注入 `window.uartix`——键盘 / 光标监听、AI 思维链感知（onChat）、向 AI 提问（ask，忙时自动排队）、自定义右键菜单（多命名菜单 + 子菜单）、窗口控制（拖拽 / 置顶 / 点击穿透）、挂件间互感广播、语音播报（speak）、主题订阅（onTheme）
- **无边框形态**：透明窗口 + 全窗按住拖拽 + 松开吸附停靠 + 边界钳制，可做悬浮仪表盘、通知条、桌面宠物（示例玩法，能力完全通用）
- **思维链多段展示**：DeepSeek 风格计时折叠，续写轮次另起新框按序排列；安装卡片流式守卫——内容未生成完毕不给安装按钮
- **token 经济**：轻底座提示词 + `[[need]]` 规范自取续写 + 关键词路由预注入 + 两级上下文摘要
- **主题桥**：沙箱组件实时跟随全局换肤（14 个 CSS 变量 + 主题标记注入），AI 生成的挂件 / 面板与主界面配色永远一致

## 帧画布与协议

- 协议簇 / 单协议右键**导出 JSON 分享包**，导入方以副本追加不覆盖
- 骨架态「未见有效帧」徽标：附四步排查提示（连接 / 波特率 / 帧头 / 识别位抢占）
- 导入预设防呆：重复导入同预设时给出计数确认
- 帧头 / 帧尾字节编辑统一收口：支持清空（无帧头的逗号分隔文本流合法）、非法输入即时红框
- 新建协议对话框：单协议 / 协议簇 / 自适应文本帧（JustFloat 式）三合一

## 界面与体验

- **深度面板中英双语**：帧画布、属性面板、控制画布、卡片设置、协议模板、面板页签全部跟随语言设置即时切换（协议名 / 字段名等用户数据保持原文）
- **默认主题改为海棠**（全新安装生效；九套主题色卡任选）
- 自定义布局槽位：工作区另存 / 一键切换 / 删除，切预设前自动备份
- 帮助新增「AI 助手详解」页：块速查 / 动作清单 / uartix API / 无边框形态玩法
