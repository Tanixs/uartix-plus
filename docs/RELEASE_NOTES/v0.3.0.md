# Uartix+ v0.3.0

性能与可视化体验大版本：2D 曲线全面重构、IPC 二进制化、面板生命周期门控、拔线自愈。

## 2D 曲线

- **双游标测量**：时间尺（垂直）+ 幅度尺（水平）独立控制，测量面板可拖拽、位置持久化
- **指针读数**：指针十字贴近曲线交点处显示原始 x/y 值（按通道原值、通道配色）
- **相对秒时间轴**：0s / 60s / 1.2h，不再显示原始时间戳
- **最新线锚定**：最新线始终贴住可见通道曲线真实末点
- **Y 轴自动贴合**持续生效；新增一次性 **Auto 键**（X+Y 一步适配最佳观察视野）
- **峰谷保形抽稀**覆盖全部通道：每个分桶保留最小/最大值点与首末点，平坦或隐藏通道不再引起曲线崎岖，且**全量数据始终完整保留**（游标、表格、导出均使用全量数据）
- 视窗裁剪喂数：重绘成本只与视野内点数相关，长时间采集不再越跑越卡

## 性能与稳定

- **IPC 全面二进制化**：帧数据经 Tauri Channel 直推 ArrayBuffer，去除 base64/JSON 开销，字符串按批字典去重
- **面板生命周期门控**：关闭面板即彻底停止后台数据搬运；堆叠面板中后台标签只缓冲不渲染、切回秒级补全；前台全速
- 收流期间应用本体不再被拖动全量重渲染
- 串口枚举/打开/发送全部异步化；GPU 合成恢复，渲染交还显卡
- **拔线检测与自动重连**：串口拔出 2 秒内正确转断开状态并支持重连；TCP 连接超时 3 秒；UDP 错误容错持续运行

## 新功能

- **视频传输（图传）面板**：网络图传源、解析设置、暂停/继续/镜像/翻转/保存
- 控制画布：卡片复制粘贴、最小 1×1 几何保护、统一定量网格对齐
- 键盘遥控卡片锁定 n×n 正方形；脚本模式自动填充示例脚本
- 3D 姿态变量支持跨模板选择（模板簇 → 帧型 → 字段 层级下拉）
- 6 套新主题（深蓝/浅蓝/护眼绿/琥珀/海棠/琉璃），色卡网格选择
- 波特率：手动输入 + 14 档预设下拉
- 设置页新增 About 作者卡片
