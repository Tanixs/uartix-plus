# 第二部分：核心卖点（官网可直接使用）

## 卖点 1：零代码，拖拽即定义协议

**标语**：框选即字段，你的协议你做主。

**详细说明**：
传统串口工具把协议解析写死在代码里——想支持自己的协议，要么改源码，要么写配置脚本。
Uartix+ 的帧画布把协议变成"画"出来的：在字节格上按住左键拖出一片区域，右键定义为字段，
取名、指定类型（U8/U16/S32/Float…）与缩放，立即生效。帧头、帧尾、功能码、校验位全部
可视化编辑，字段长度与数据类型自动匹配，冲突区域自动提示。改完保存，解析立即更新——
从"拿到一份数据手册"到"看到解析结果"，最快只要 1 分钟。

## 卖点 2：多协议并行解析引擎

**标语**：一个窗口，同时看清多种设备的心跳。

**详细说明**：
内置协议簇：匿名 V7（22 种帧型）、维特 WIT 陀螺仪、Modbus RTU、NMEA-0183、
自适应 CSV 文本帧、JustFloat 式定长帧……多个协议簇可**同时启用、同一条数据流上并行
解析**，各自独立筛选有效帧。协议识别支持"帧头 + 功能码识别位 + 校验"三重判定，
误码率与粘包场景下依然稳定。所有预设开箱即用，也支持导入/导出分享给同事。

## 卖点 3：串口 + 网络，一套管线

**标语**：插串口还是接网线，体验完全一致。

**详细说明**：
除传统串口（最高 3M 波特率、热插拔检测、断线自动重连）外，v0.2.0 起**原生支持
TCP 客户端 / TCP 服务端 / UDP**。网络数据与串口走完全相同的解析、绘图与控制管线——
Hex 流、协议解析、曲线、指令下发对所有接口一视同仁。设备在网络那一端？
换一个接口类型就行，其他一切不变。

## 卖点 4：从原始字节到曲线，一站式可视化

**标语**：Hex 流、帧结构、曲线、表格、3D 姿态——同一份数据的五种视角。

**详细说明**：

- **Hex 数据流**：原始字节总览，框选定义字段、Ctrl+F 搜索定位
- **2D 曲线**：字段图例点亮即绘，多线型（直线/阶梯/样条）、框选缩放、实时采样率显示
- **3D 姿态**：欧拉角/四元数直接映射 3D 模型，适合 IMU 调试
- **数据表格**：逐帧列表，排序/筛选，一键导出 CSV / Excel
- **控制台**：彩色时间戳，ASCII/Hex 双模式，收发分离

## 卖点 5：指令工厂 + 快捷指令，调试闭环的最后一块

**标语**：不发"看不懂的十六进制"，发"看得懂的指令"。

**详细说明**：
- **快捷指令栏**：常用指令一键发送，悬停即预览实际字节（自动识别 Hex/ASCII/脚本）
- **指令工厂**：内置 WIT 寄存器、匿名 V7 功能触发/参数读写、Modbus RTU 与校验工具
  ——选寄存器、填值，帧与校验自动生成，分段着色预览每个字节的来源
- **自定义协议模板**：固定字节 + 变量字段 + 长度段 + 校验段可视化组合，
  你单片机的私有协议 1 分钟变成"填空题"
- 所有指令可拖挂到控制画布，变成面板上的实体按键

## 卖点 6：控制画布——把调试面板拼出来

**标语**：滑条、按钮、开关、仪表——像搭积木一样搭你的上位机。

**详细说明**：

# 第三部分：产品说明文档（可作官网 docs 底稿 / 随软件内置帮助）

## 1. Uartix+ 是什么

Uartix+ 是一款**可视化串口/网络协议分析仪**：连接你的设备（串口或网络），
定义或导入通信协议，软件自动筛选有效帧并解析，在字节流、帧结构、曲线、表格、
3D 姿态等多种视图上呈现干净数据；再通过控制画布与指令工厂向设备下发指令，
形成"观察 → 分析 → 控制"的完整调试闭环。

- 平台：Windows 10/11（NSIS 安装包）、Linux（AppImage / deb）
- 协议：MIT 开源，github.com/Tanixs/uartix-plus

## 2. 快速上手（五步）

1. 标题条选择**数据接口**（串口 / TCP 客户端 / TCP 服务端 / UDP），完成参数设置后点「连接」。
2. 左侧「协议模板」面板点「＋ 预设」导入协议（匿名 V7 / 维特 WIT / Modbus / CSV 文本帧），或「＋ 新建」自定义。
3. 没有设备？点左下角「启动演示源」，软件会生成混合协议数据流供体验。
4. 中央「帧画布」查看每帧字节结构（绿=字段、橙=帧头、粉=校验），悬停看实时数值。
5. 「2D 曲线」点亮字段图例的眼睛开始绘图；「数据表格」查看帧列表并可导出。

## 3. 数据接口

| 接口 | 参数 | 说明 |
|---|---|---|
| 串口 | 端口/波特率/数据位/校验/停止位 | 支持热插拔检测；断线自动重连；最高 3M baud |
| TCP 客户端 | 远程 IP + 远程端口 | 主动连接设备；断线自动重连 |
| TCP 服务端 | 本地监听端口 | 等待设备接入；新连接自动替换旧连接 |
| UDP | 本地绑定端口 + 默认对端 | 接收任意来源，发送到默认对端 |

注意：
- 网络数据与串口使用**完全相同**的解析/绘图/控制管线。
- 远程地址填 `127.0.0.1` 时数据会发给自己（本机回环），适合自测。
- 首次监听端口请在 Windows 防火墙弹窗中**允许访问**。
- 网络已连接但通道未就绪（TCP 重连中/服务端无客户端）时发送会明确提示。

## 4. 协议定义

### 4.1 使用预设
「协议模板 → ＋ 预设」：匿名 V7（22 帧型）、维特 WIT、Modbus RTU、NMEA-0183、
CSV 自适应文本帧。预设含帧头/长度/校验与字段缩放，导入即用。

### 4.2 帧画布（零代码自定义）
1. 收到数据后，画布显示真实字节流；未收到数据时显示骨架格，同样可编辑。
2. **左键框选**字节格 → 右键「定义为字段」：设名称/类型/缩放/单位。
3. 字段长度自动随类型扩展；区域冲突会提示。
4. 右键帧头/帧尾可修改字节，甚至删除（支持无帧头的逗号文本帧）。
5. 右键帧内可插入/删除字节格（帧长自动 ±1，字段偏移自动调整）。
6. 右键帧可启用「识别位」（如功能码），实现同帧头多帧型区分。
7. 「保存」立即生效并持久化；协议模板可分组、复制/粘贴帧型、导入导出。

### 4.3 校验
支持 sum8/sum16/XOR8/CRC16-Modbus/CRC16-CCITT 等校验，作为帧尾判定条件参与
有效帧筛选（错帧计入统计并标红）。

## 5. 数据可视化

- **2D 曲线**：图例点眼睛开关通道；直线/阶梯/样条三种线型；拖动平移、
  中键框选缩放、双击复位、滚轮缩放（轴区对应轴）；显示实时采样率。
- **3D 姿态**：把欧拉角或四元数字段映射到 3D 模型。
- **数据表格**：逐帧列表，排序/筛选/列显隐，导出 CSV 与 Excel（仅含显示列）。
- **Hex 数据流**：原始字节总览 + 框选定义字段 + Ctrl+F 搜索。

## 6. 控制与指令

### 6.1 控制台
ASCII/Hex 双模式收发、彩色时间戳、追加换行符、发送历史、收发分离显示、
暂停/自动滚动、发送文件（自动分块）、录制日志。

### 6.2 快捷指令栏
- 命令芯片左键**立即发送**，悬停预览实际内容与字节数
- 与控制画布命令树同库共享，改动双向互通

### 6.3 指令工厂
| 协议 | 说明 |
|---|---|
| WIT 写寄存器 | 30+ 寄存器 + 常用值；自动"解锁→写入→保存"序列 |
| 匿名V7 功能触发 (0xE0) | 24 条命令表，参数按类型小端填充，SC+AC 自动 |
| 匿名V7 参数读写 (0xE1/0xE2) | PAR_ID + PAR_VAL(S32 补码) |
| Modbus RTU | 01~06 功能码，CRC16 自动 |
| 校验工具 | SUM8/XOR8/SUM16/CRC16×3/匿名SC+AC，可追加帧尾 |
| 我的协议 | 自定义帧模板（见 6.4） |

### 6.4 自定义协议模板
帧 = 段序列：**固定字节**（帧头等）+ **变量字段**（U8~U32/S16/S32/F32/文本，
小端/大端）+ **长度段**（自动计算）+ **校验段**（7 种算法）。
实时预览、按字段着色，保存后与内置协议同样使用。

### 6.5 控制画布
- 控件：滑条、按钮、开关、LED、蜂鸣器、数值监视、摇杆
- 拖拽：虚线幽灵框指示落点，只落空格，绝不重叠
- 每控件可绑定指令模板或 JS 脚本（`send` / `beep` / `delay_ms` / `get`，
  变量插值 `{温度:.1f}`、printf 风格 `%d`）
- 命令库（递归分组 + 脚本）全局共享，拖挂即用

## 7. 设置与数据管理

- 亮/暗主题、界面缩放（90~125%）、界面语言（中文/英文）

## 8. 常见问题（FAQ）

**Q：串口列表里没有我的设备？**
A：CH340/CP210x 等需安装厂商驱动；Linux 下把用户加入 dialout 组。

**Q：能解析但曲线不动？**
A：确认字段"缩放"设置正确；曲线通道需在图例中点亮眼睛。

**Q：TCP 发送提示"网络连接尚未就绪"？**
A：TCP 正在连接/重连，或服务端模式还没有设备接入；等状态栏显示"已连接"再发。

**Q：UDP 发给自己收到了两次显示？**
A：远程地址填 127.0.0.1 是本机回环，TX 与 RX 都是你自己的包，属正常自测现象。

**Q：Windows 打开安装包提示未知发布者？**
A：安装包暂未做数字签名，点"更多信息 → 仍要运行"。

**Q：首发监测端口时弹防火墙？**
A：允许访问，否则外部设备无法连入。
