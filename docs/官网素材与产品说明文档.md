# 第二部分：核心卖点（官网可直接使用）

## 卖点 1：零代码，拖拽即定义协议

**标语**：框选即字段，你的协议你做主。

**详细说明**：
传统串口工具把协议解析写死在代码里——想支持自己的协议，要么改源码，要么写配置脚本。
Uartix+ 的帧画布把协议变成"画"出来的：在字节格上按住左键拖出一片区域，右键定义为字段，
取名、指定类型（U8/U16/S32/Float…）与缩放，立即生效。帧头、帧尾、功能码、校验位全部
可视化编辑，字段长度与数据类型自动匹配，冲突区域自动提示。改完保存，解析立即更新——
从"拿到一份数据手册"到"看到解析结果"，最快只要 1 分钟。

## 卖点 2：多协议并行解析引擎

**标语**：一个窗口，同时看清多种设备的心跳。

**详细说明**：
内置协议簇：匿名 V7（22 种帧型）、维特 WIT 陀螺仪、Modbus RTU、NMEA-0183、
自适应 CSV 文本帧、JustFloat 式定长帧……多个协议簇可**同时启用、同一条数据流上并行
解析**，各自独立筛选有效帧。协议识别支持"帧头 + 功能码识别位 + 校验"三重判定，
误码率与粘包场景下依然稳定。所有预设开箱即用，也支持导入/导出分享给同事。

## 卖点 3：串口 + 网络，一套管线

**标语**：插串口还是接网线，体验完全一致。

**详细说明**：
除传统串口（最高 3M 波特率、热插拔检测、拔线秒级识别、断线自动重连）外，**原生支持
TCP 客户端 / TCP 服务端 / UDP**。网络数据与串口走完全相同的解析、绘图与控制管线——
Hex 流、协议解析、曲线、指令下发对所有接口一视同仁。设备在网络那一端？
换一个接口类型就行，其他一切不变。

## 卖点 4：从原始字节到曲线，一站式可视化

**标语**：Hex 流、帧结构、曲线、表格、3D 姿态、图传——同一份数据的六种视角。

**详细说明**：

- **Hex 数据流**：原始字节总览，框选定义字段、Ctrl+F 搜索定位、独立暂停按钮
- **2D 曲线**：字段图例点亮即绘，多线型（直线/阶梯/样条）、框选缩放、实时采样率显示、
  双游标测量、指针坐标跟随、相对秒时间轴、一键 Auto 视图适配
- **3D 姿态**：欧拉角/四元数直接映射 3D 模型，支持跨协议模板绑定字段，适合 IMU 调试
- **数据表格**：逐帧列表，排序/筛选，一键导出 CSV / Excel
- **控制台**：彩色时间戳，ASCII/Hex 双模式，收发分离
- **图传面板**：网络视频源接入，镜像/翻转/暂停/保存

## 卖点 5：指令工厂 + 快捷指令，调试闭环的最后一块

**标语**：不发"看不懂的十六进制"，发"看得懂的指令"。

**详细说明**：
- **快捷指令栏**：常用指令一键发送，悬停即预览实际字节（自动识别 Hex/ASCII/脚本）
- **指令工厂**：内置 WIT 寄存器、匿名 V7 功能触发/参数读写、Modbus RTU 与校验工具
  ——选寄存器、填值，帧与校验自动生成，分段着色预览每个字节的来源
- **自定义协议模板**：固定字节 + 变量字段 + 长度段 + 校验段可视化组合，
  你单片机的私有协议 1 分钟变成"填空题"
- 所有指令可拖挂到控制画布，变成面板上的实体按键

## 卖点 6：控制画布——把调试面板拼出来

**标语**：滑条、按钮、开关、仪表——像搭积木一样搭你的上位机。

**详细说明**：
从控件库拖入滑条、按钮、开关、LED、蜂鸣器、数值监视、摇杆，网格对齐、碰撞防重叠、
所见即所得。每个控件绑定指令模板或 JS 脚本（支持变量插值、延时序列、条件发送），
并与协议解析变量实时联动——收到什么数据、点亮什么灯、发送什么指令，全部拖拽配置。
布局支持多页面与导入导出，一次搭好，团队复用。

## 卖点 7：Rust 内核，为长时间调试而生

**标语**：跑一天一夜，依然丝滑。

**详细说明**：
解析内核用 Rust 实现：环形缓冲 + 帧归档池水位线回收 + 事件批处理 + 视窗裁剪喂数
（只渲染看得见的），38 万帧持续灌入不卡顿、不丢帧；二进制 IPC 通道 + GPU 加速渲染，
多线程解析不阻塞 UI；面板关闭即彻底停止后台，不偷跑资源。串口/TCP/UDP 断联
自动检测重连（拔线秒级识别）。自动更新、崩溃可查的日志记录、9 款主题，桌面级完成度。

## 卖点 8：开源 MIT，数据与协议都在你手里

**标语**：MIT 协议，自由使用、自由修改、自由分发。

**详细说明**：
源码托管于 GitHub，无广告、无遥测、不联网上传任何数据。
协议模板、控制页、命令库、快捷指令全部本地 JSON 存储，导入导出即分享。

## 卖点 9：图传接入，画面与数据同屏

**标语**：网络图传直连，姿态、曲线、画面一屏尽览。

**详细说明**：
内置视频传输面板，TCP/UDP 图传源直接接入——无人机的画面和 IMU 遥测在
同一个窗口里对照查看。镜像/水平翻转一键切换，暂停、保存、清空触手可及，
解析参数可视化配置。航模、机器人地面站调试，不用再开第二个软件。

## 卖点 10：双游标测量，示波器级分析

**标语**：两条游标，读出任意两点的时间差与幅值差。

**详细说明**：
时间游标（垂直）与幅值游标（水平）独立放置、支持整体拖动，测量面板实时
显示两条游标的坐标与 A−B 差值；指针交叉线自动吸附最近曲线，就近显示原始
x/y 数值。时间轴以相对秒显示（0s / 60s / 1.2h），长时采集一目了然。
一键 Auto 智能适配视野，Y 轴自动贴合让曲线始终占满可视区。

## 卖点 11：键盘遥控，电脑变遥控器

**标语**：WASD 直控你的车，脚本分支随你定义。

**详细说明**：
键盘遥控卡片把物理按键映射成指令：点按即发，支持 JS 脚本模式——按方向
分支发送不同指令、变量插值、延时序列都能写。卡片锁定 n×n 方阵布局，
还原真实遥控器的手感。小车、云台、机械臂的桌面调试，键盘就是遥控器。

## 卖点 12：AI 助手——能创造、能执行、能感知（v0.3.6）

**标语**：说出来，协议、面板、悬浮小部件就都生成好了。

**详细说明**：
内置 AI 不是聊天机器人，而是应用内引擎：对话即可生成协议模板、控制卡片、
命令库、主题、可停靠面板，甚至**无边框悬浮挂件**（按住即拖、松开停靠、
右键菜单自定义），全部以确认卡片一键安装。操作类诉求（打开面板、切布局、
连串口）由 AI 直接执行。所有沙箱组件自动获得 `uartix` API——键盘/光标监听、
AI 思维链感知、向 AI 提问、挂件互感、语音播报、主题跟随；换肤实时同步。
思维链多段流式展示，内容未生成完毕不给安装按钮，安全兜底永远在人。

## 卖点 13：工业 Modbus 全流程（v0.3.8）

**标语**：没有 485 设备，也能把整条总线跑通。

**详细说明**：
RTU / TCP 整簇预设开箱即用：帧头位掩码一条模板吃下整条总线的任意从站地址，
读响应自动展开 `寄存器1..N`、线圈区按位展开 `线圈1..N`（一位一通道直接画曲线），
异常码自带规范文字（「2 非法数据地址」）。**Modbus 工作台**面板内置模拟从站
（四张可编数据表 + 故障注入：不回应答 / 指定异常码 / 应答延时）与主站轮询表
（按周期读寄存器写成变量），关掉面板仍在运行——自发自收就能验证解码链路。

## 卖点 14：时间机器——全面板同步录制回放（v0.3.7）

**标语**：每一次现场，都可以倒带。

**详细说明**：
把整场会话（解析帧流 + 原始收发）录成 `.usess` 文件，回放引擎跑在 Rust 侧与
演示源同构——帧画布 / 曲线 / 表格 / 姿态 / Hex 全面板零延迟同步倒带，0.25× 起
多档倍速、进度条点选跳转、按 M 打时间线标注（2D 曲线上画琥珀虚线）。
回放还能桥接成 TCP 服务端，把录制会话当「虚拟设备」喂给第三方工具联调。
配套的**结构发现**面板对未知协议做周期/帧头/列熵统计推断与**校验算法爆破**，
AI 考古报告只许引用确定性证据链编号推理。

## 卖点 15：3D 轨迹与校准全家桶（v0.4.1）

**标语**：轨迹看得见，磁干扰也能被数学地除掉。

**详细说明**：
任意三个字段画实时三维轨迹（航迹/相图/姿态积分），双层 LOD 十万点长跑不卡，
经纬度级大坐标自动重锚；键盘飞行、跟随模式、底部时间条与回放联动。
**椭球校准**八象限点云采样 → 九参数最小二乘（硬磁偏置 + 软磁对称校正矩阵），
残差着色、校正前后对比、在线补偿预览，一键复制 JSON / C 数组进固件；
**加计六面向导**静置六个面自动解算。频谱分析面板（FFT/直方图）与 2D 共享通道。

## 卖点 16：会自己动的调试——序列器 × 编排器 × PID 自整定（v0.3.9 / v0.4.1）

**标语**：从"人肉点按钮"升维到"描述一遍，它自己跑"。

**详细说明**：
**测试序列器**拖积木组自动化测试（帧触发/单步/HTML 报告），CLI 带内置回环设备
与 JUnit 输出进 CI。**自动编排器**融合触发器语义：12 类事件（帧/坏帧/新帧型/
阈值/通道变化/定时器/会话/哨兵/变量/自定义事件/静默）挂到组上自动触发，
23 类块线性执行，FIFO 队列 + 冷却 + 三重熔断。**内置 PID 继电反馈整定模板**——
阈值事件数摆动周期，自动算出 Kp/Ti/Td 回发设备，串口工具圈少见的自动调参。

## 卖点 17：虚拟设备工坊——让软件扮演一台真设备（v0.4.1）

**标语**：设备没到货的这三周，工作流一天都不停。

**详细说明**：
一份 JSON 规格 = 一台虚拟仪器：六种信号模型（含一阶惯性对象）、噪声与温漂、
丢帧/卡死/毛刺故障、帧格式打包、命令匹配应答（`SET DUTY 45` 数值捕获），
还能选 UDP / TCP / 串口**对外收发**——另一台电脑或第三方软件连进来，
看到的就是逐字节一致的真数据流。内置温控炉与虚拟 MPU6050；对 AI 说一句
「模拟一个有温漂偶尔丢帧的 MPU6050」即生成入库启动。

## 卖点 18：哨兵——替你盯着总线的那个夜班同事（v0.3.9）

**详细说明**：
双 EMA z-score 通道突变、学习期后新帧型、错误帧率、通信静默四类检测，
报警冷却合并降噪；右下角浮球 / 桌面挂件驻留，合成提示音分级；严重报警
一键或自动发起 **AI 根因诊断**（携带结构化证据，不弹窗不抢焦点）。

## 卖点 19：MCP 服务器与 Operator 部署包——集成与交付的两端（v0.3.9）

**详细说明**：
把 Uartix+ 暴露成 **MCP 服务**，Claude Desktop / Cursor 里的智能体直接查实时
遥测、发指令、跑测试序列（10 个工具；token 握手 + 独立权限门 + 调用审计）。
反过来，把调好的工作区打成 **`.uopk` Operator 部署包**交给现场操作员：
双击导入即只读运行——配置写入被 store 层统一拦截，连设备、发命令、看数据照常。

## 卖点 20：交互式教学与十页签帮助（v0.4.1）

**详细说明**：
第一次启动即有 9 步聚光灯引导走通主流程（连接→演示源→预设→帧画布→曲线→
控制→AI），随时 Esc 退出；帮助弹窗十个页签覆盖快速入门、面板总览、AI 详解、
协议画布教程、3D 轨迹、自动编排器、脚本、快捷键、导出格式、部署分发。

## 与常见工具的定位差异（官网可用措辞，注意措辞克制）

# 第三部分：产品说明文档（可作官网 docs 底稿 / 随软件内置帮助）

## 1. Uartix+ 是什么

Uartix+ 是一款**嵌入式可视化上位机**：向下连接你的下位机（单片机 / 惯导 /
机器人 / 控制板，走串口或网络），向上把原始字节变成结构、数值、曲线与画面，
再把操作回写成设备能接受的指令。定义或导入通信协议后，软件自动筛选有效帧并解析，
在字节流、帧结构、曲线、表格、3D 姿态等多种视图上呈现干净数据；再通过控制画布与
指令工厂向设备下发指令，形成"观察 → 分析 → 控制"的完整调试闭环。

- 平台：Windows 10/11（NSIS 安装包）、Linux（AppImage / deb）
- 协议：MIT 开源，github.com/Tanixs/uartix-plus

## 2. 快速上手（五步）

1. 标题条选择**数据接口**（串口 / TCP 客户端 / TCP 服务端 / UDP），完成参数设置后点「连接」。
2. 左侧「协议模板」面板点「＋ 预设」导入协议（匿名 V7 / 维特 WIT / Modbus / CSV 文本帧），或「＋ 新建」自定义。
3. 没有设备？点左下角「启动演示源」，软件会生成混合协议数据流供体验。
4. 中央「帧画布」查看每帧字节结构（绿=字段、橙=帧头、粉=校验），悬停看实时数值。
5. 「2D 曲线」点亮字段图例的眼睛开始绘图；「数据表格」查看帧列表并可导出。

## 3. 数据接口

| 接口 | 参数 | 说明 |
|---|---|---|
| 串口 | 端口/波特率/数据位/校验/停止位 | 支持热插拔检测；断线自动重连；最高 3M baud |
| TCP 客户端 | 远程 IP + 远程端口 | 主动连接设备；断线自动重连 |
| TCP 服务端 | 本地监听端口 | 等待设备接入；新连接自动替换旧连接 |
| UDP | 本地绑定端口 + 默认对端 | 接收任意来源，发送到默认对端 |

注意：
- 网络数据与串口使用**完全相同**的解析/绘图/控制管线。
- 远程地址填 `127.0.0.1` 时数据会发给自己（本机回环），适合自测。
- 首次监听端口请在 Windows 防火墙弹窗中**允许访问**。
- 网络已连接但通道未就绪（TCP 重连中/服务端无客户端）时发送会明确提示。

## 4. 协议定义

### 4.1 使用预设
「协议模板 → ＋ 预设」：匿名 V7（22 帧型）、维特 WIT、Modbus RTU、NMEA-0183、
CSV 自适应文本帧。预设含帧头/长度/校验与字段缩放，导入即用。

### 4.2 帧画布（零代码自定义）
1. 收到数据后，画布显示真实字节流；未收到数据时显示骨架格，同样可编辑。
2. **左键框选**字节格 → 右键「定义为字段」：设名称/类型/缩放/单位。
3. 字段长度自动随类型扩展；区域冲突会提示。
4. 右键帧头/帧尾可修改字节，甚至删除（支持无帧头的逗号文本帧）。
5. 右键帧内可插入/删除字节格（帧长自动 ±1，字段偏移自动调整）。
6. 右键帧可启用「识别位」（如功能码），实现同帧头多帧型区分。
7. 「保存」立即生效并持久化；协议模板可分组、复制/粘贴帧型、导入导出。

### 4.3 校验
支持 sum8/sum16/XOR8/CRC16-Modbus/CRC16-CCITT 等校验，作为帧尾判定条件参与
有效帧筛选（错帧计入统计并标红）。

## 5. 数据可视化

- **2D 曲线**：图例点眼睛开关通道；直线/阶梯/样条三种线型；拖动平移、
  中键框选缩放、双击复位、滚轮缩放（轴区对应轴）；显示实时采样率。
- **3D 姿态**：把欧拉角或四元数字段映射到 3D 模型。
- **数据表格**：逐帧列表，排序/筛选/列显隐，导出 CSV 与 Excel（仅含显示列）。
- **Hex 数据流**：原始字节总览 + 框选定义字段 + Ctrl+F 搜索。

## 6. 控制与指令

### 6.1 控制台
ASCII/Hex 双模式收发、彩色时间戳、追加换行符、发送历史、收发分离显示、
暂停/自动滚动、发送文件（自动分块）、录制日志。

### 6.2 快捷指令栏
- 命令芯片左键**立即发送**，悬停预览实际内容与字节数
- 与控制画布命令树同库共享，改动双向互通

### 6.3 指令工厂
| 协议 | 说明 |
|---|---|
| WIT 写寄存器 | 30+ 寄存器 + 常用值；自动"解锁→写入→保存"序列 |
| 匿名V7 功能触发 (0xE0) | 24 条命令表，参数按类型小端填充，SC+AC 自动 |
| 匿名V7 参数读写 (0xE1/0xE2) | PAR_ID + PAR_VAL(S32 补码) |
| Modbus RTU | 01~06 功能码，CRC16 自动 |
| 校验工具 | SUM8/XOR8/SUM16/CRC16×3/匿名SC+AC，可追加帧尾 |
| 我的协议 | 自定义帧模板（见 6.4） |

### 6.4 自定义协议模板
帧 = 段序列：**固定字节**（帧头等）+ **变量字段**（U8~U32/S16/S32/F32/文本，
小端/大端）+ **长度段**（自动计算）+ **校验段**（7 种算法）。
实时预览、按字段着色，保存后与内置协议同样使用。

### 6.5 控制画布
- 控件：滑条、按钮、开关、LED、蜂鸣器、数值监视、摇杆
- 拖拽：虚线幽灵框指示落点，只落空格，绝不重叠
- 每控件可绑定指令模板或 JS 脚本（`send` / `beep` / `delay_ms` / `get`，
  变量插值 `{温度:.1f}`、printf 风格 `%d`）
- 命令库（递归分组 + 脚本）全局共享，拖挂即用

## 8. 常见问题（FAQ）

**Q：串口列表里没有我的设备？**
A：CH340/CP210x 等需安装厂商驱动；Linux 下把用户加入 dialout 组。

**Q：能解析但曲线不动？**
A：确认字段"缩放"设置正确；曲线通道需在图例中点亮眼睛。

**Q：TCP 发送提示"网络连接尚未就绪"？**
A：TCP 正在连接/重连，或服务端模式还没有设备接入；等状态栏显示"已连接"再发。

**Q：UDP 发给自己收到了两次显示？**
A：远程地址填 127.0.0.1 是本机回环，TX 与 RX 都是你自己的包，属正常自测现象。

**Q：Windows 打开安装包提示未知发布者？**
A：安装包暂未做数字签名，点"更多信息 → 仍要运行"。

**Q：首发监测端口时弹防火墙？**
A：允许访问，否则外部设备无法连入。

**Q：图传面板没有画面？**
A：确认网络源类型（TCP/UDP）与地址端口和设备端推流一致，并在解析设置中选择正确的视频参数；服务端模式需等待设备接入。

**Q：拔掉串口后软件会卡住吗？**
A：不会。设备拔出后 2 秒内自动检测并断开，重插后重新连接即可；TCP/UDP 断联同样自动检测重连。
