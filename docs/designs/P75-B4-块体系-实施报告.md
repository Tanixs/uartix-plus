## 三、B4b：表达式白名单函数

- `expr.ts` 新增 `FUNCS` 表 10 个纯函数：`abs/floor/ceil/round/min/max/clamp/if/len/fmt`。
- 语法：`ident(args…)` 调用 + 逗号记号；未知函数**语法期**即报错并列出可用清单。
- `if` 函数惰性求值：只求值被选中的分支（另一分支引用未声明变量也不报错）。
- 红线从"无函数调用"改为"仅白名单纯函数"；沙箱三重保护（深度帽/节点帽/deadline）不变。Inspector 表达式提示文案同步更新。

## 五、B4d：新事件块（+5）

| 事件 | 语义 |
|---|---|
| frameError | 解码失败帧（valid=false）命中；复用帧流零新增管道；stride 取样；ctx 注入 evt.len/tplName |
| newTpl | 出现新帧型；tplId 空 = 任意帧型；帧流 onFrames 热路径按 needTplWatch 门控 Set 查询 |
| chanChanged | 通道值变化超容差；tick 检测器自归属（groupId/blockId），minIntervalMs 防抖；ctx 注入 old/new |
| flowEvt | 监听 emitFlow 派发的自定义流事件；同名匹配；data 键直接进 evt 上下文 |
| idle | 通信静默计时；有帧数据流自动重武装（needIdleArm 门控，热路径零成本） |

- `FlowEvent` 联合新增 `frameError/chanChanged/flow/idle/newTpl` 5 种。
- bind：`rebuildSources` 构建 chanWatch/idleBlocks 注册表；帧流入口扩展（坏帧/新帧型事件 + idle 重武装）。
- 全链路同 B4c：registry/makeEvent/normalize/buildAiEvent/pendingHints/Inspector 事件编辑器/Panel eventSummary。

## 六、B4e：多帧 + 模板 + 空态引导

1. **resolveSend 多帧透传**：`SendPayload` 的 factory 分支新增 `{ type:"factoryMulti"; codecId; vals }`（返回 `ResolvedSend = 单帧形态 | { frames: string[] }`）；sequencerBind codec 多帧全量返回；runner execSend 逐帧发送（`HEX×N 共 N 字节` 日志）；编排器 hex 分支逐帧插值。引擎 send 块多帧时每帧过令牌桶，中途超限 fail 带 `已发/总数`。
2. **内置组模板**：`orchestratorPresets.ts` 4 套——报警通知（阈值→toast+音）/ 看门狗（idle→crit+喂狗帧）/ 定时轮询（timer→Modbus FC03 示意帧）/ 收发握手（帧→回复→等确认→if 通知）。`importPresetGroup` 走 guardLocked + groupCap 红线，**导入默认未启用**。
3. **空态引导卡**：加「从模板新建」内联下拉（4 模板一键导入）+「让 AI 帮我搭」直达（chatStore.requestAsk 预填提问）；新增 `.orch-empty-ops/.orch-preset-*` CSS。
