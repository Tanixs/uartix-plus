# P69 详设：3D 空间轨迹面板（plot3d）

状态：待确认 → 开工
批次：P69（与发版 v0.3.9 同批）
参考基准：本文所有交互/性能决策均对照开源项目调研结论，来源见 §2。

---

## 1. 定位与目标

一句话：**任意三个数值字段 → 实时 3D 轨迹/散点/相图，自由视角 + 时间回放 + 测量**。

应用场景（按用户群优先级）：

| 场景 | 绑定方式 | 备注 |
|---|---|---|
| 无人机/GPS 航迹 | X=东向偏移 Y=北向偏移 Z=高度 | 俯视正交视角 + 测距 = 航线规划验证 |
| 加计/陀螺相位空间 | X=ax Y=ay Z=az | 相图/李萨如，振动模式直观化 |
| 机械臂末端轨迹 | X/Y/Z=末端坐标 | 教学的可视化验证 |
| AGV/小车路径 | X/Y=位置 Z=速度或时间 | 环形轨迹压线检查 |
| 磁力计/加计校准 | 三轴原始值 + T3 椭球拟合 | 惯导用户刚需，见 §11 T3 |
| 时间机器回放 | 会话录制回放时同步 | 「飞行还原」，竞品无 |

非目标：不做点云（LiDAR 级百万点）、不做 URDF/TF（那是 3D 姿态面板的域）、不做地图底图。

## 2. 开源调研与借鉴结论

| 项目 | 借鉴点 | 采纳/否决 |
|---|---|---|
| **Foxglove Studio 3D 面板**（MPL-2.0，机器人可视化事实标杆） | 相机操作矩阵（拖拽=地面平移、右键拖=绕目标旋转、滚轮缩放、WASD 飞行）；Follow Mode 四档（Off/Position/Heading/Pose）；设置按「层」分组 | 采纳相机矩阵的**简化版**（我们是轨迹图不是场景图：拖拽=旋转、右键=平移+菜单）；Follow 简化为 Off/Position 两档；右键菜单分组方式符合本项目菜单规范 |
| **three.js 官方 fat lines 示例**（Line2/LineMaterial） | 屏幕空间粗线 | **T1 否决**：Line2 是实例化线段，10 万点内存翻倍且 Windows ANGLE 兼容性风险；用 1px `THREE.Line` + 顶点色渐隐（T2 按需给「短窗口粗线」选项） |
| **kepler.gl trip 层** | 时间游标 + 轨迹渐进生长 + trail length（尾迹窗口） | 采纳「尾迹窗口」概念：渐隐窗口可调（最近 N 秒 / 全程） |
| **RViz** | 视角预设（俯/侧/前/等轴）、网格自适应刻度 | 采纳预设四视角；网格 nice-number 刻度 |
| **uPlot min/max 抽稀**（本项目 2D 已用） | 峰谷保留抽稀 | 3D 轨迹用时间抽稀（轨迹抽掉中间点肉眼不可辨，无需保峰谷） |

GitHub 直连已验证可达，无需代理/服务器中转。

## 3. 数据流与复用架构（核心复用点）

### 3.1 通道模型：完全复用 plotStore

```
framesBus → plotStore.appendPoint() → ChanData{t[],v[]}（每通道环形 30k）
                    ↓ buildAligned()（多路归并 + null 前向填充 + 增量缓存）
        对齐后 cols[][] ──→ 2D 曲线 / 频谱（现状）
                    └──→ 3D 轨迹（新增消费方，零重复逻辑）
```

关键结论：**三通道时间对齐不用写一行新代码**。`buildAligned()` 已按合并时间轴归并各通道并前向填充 null——X/Y/Z 三列直接取出来就是逐时刻对齐的 xyz 序列。时间戳跨帧、不同帧率等问题已被现有机制覆盖。

- 通道列表与 2D 曲线**共享**（同频谱模式：加一次通道，到处可用）
- 3D 面板独立设置：`axisX/axisY/axisZ`（绑通道 id）+ `colorBy`（time 或通道 id）
- 采集门控：`plotStore.init()` 的 `panelActivity.isOpen` 判断加入 `"plot3d"`（一行改动）

### 3.2 增量喂数

`plotStore.isDirty()` 已有脏标记。3D 渲染循环每帧：

1. `isDirty()` → `clearDirty()` → 从上次消费到的合并轴下标起取新增段（本面板自记 `lastConsumed`，数据被裁剪/换绑定时全量重灌）
2. 新点写入预分配 `Float32Array` 环形（见 §10），`drawRange` 前移
3. 非 dirty 且相机静止 → 跳过 render（GPU 0 负载）

## 4. 渲染方案

- **轨迹线**：`THREE.Line` + 预分配 `BufferGeometry`（position + color），`setDrawRange` 增量绘制
- **渐隐**：顶点 RGB 向背景色 lerp（不依赖逐顶点 alpha，浅/深主题都正确，无混合顺序问题）；窗口=「最近 N 秒」或「全程」（kepler 尾迹概念）
- **最新点**：Sprite 圆点标记（accent 色）
- **网格**：`GridHelper`（XZ 平面）+ 三轴短线 + 轴标签 Sprite（X/Y/Z + 字段名+单位）；刻度 nice-number 自包围盒
- **背景/网格配色**：读 CSS 变量（`--bg-inset`、`--border` 等），`renderer.setClearColor` 跟主题，浅色默认
- **悬停拾取**：自建屏幕空间最近点搜索（时间窗二分 + 逐点投影距离），返回轨迹下标 → tooltip 显示 t/xyz/绑定字段值；不用 Raycaster 拾取 Line（阈值难控）

## 5. 交互契约（重点，全量列出）

### 5.1 鼠标

| 操作 | 行为 | 说明 |
|---|---|---|
| 左键拖拽 | 旋转视角（orbit） | OrbitControls 原生，enableDamping=0.12 |
| **左键长按 ≥400ms 且位移<6px** | 进入**测距模式**：光标变十字，点两个点 → 显示 3D 距离与两点坐标；Esc/再长按退出 | 长按语义唯一且不易误触 |
| 左键双击 | 有悬停点 → target 聚焦该点；无 → 重置视角 | |
| 右键拖拽 | 平移（pan） | OrbitControls `mouseButtons.RIGHT = PAN` |
| **右键短按（位移<6px）** | 弹出上下文菜单（§5.3） | 拖拽与点击以位移阈值区分 |
| 中键拖拽 | 平移（与右键等效） | 照顾 CAD 习惯 |
| 滚轮 | 缩放 | T2 加「缩放到光标」开关 |
| 悬停 | 最近点 tooltip（点云式跟随，非十字线） | 不做 2D 那种横竖游标——3D 无此语义，tooltip 即可 |

明确不做：右键长按无第二语义（右键只有「拖=平移、点=菜单」两种，避免混淆）。

### 5.2 键盘（T2，Foxglove 简化版）

`W/A/S/D` 平移、`Q/E` 升降、方向键绕目标旋转、`F` 跟随开关、`R` 重置视角、`Esc` 退测量。仅面板聚焦时生效，不抢全局快捷键。

### 5.3 右键菜单（分层分组，与全站菜单规范一致）

```
视图 ▸ 俯视 / 侧视 / 正视 / 等轴 / 重置视角
      ─ 分隔 ─
      自动旋转 ✓/✗   网格与坐标轴 ✓/✗   跟随最新点 ✓/✗
测量 ▸ 测距模式（同长按）    清除测量
数据 ▸ 复制悬停点坐标        导出轨迹 CSV        快照 PNG        清空轨迹
设置 ▸ 轨迹样式 ▸（线+点 / 仅线 / 仅点，渐隐窗口：最近10s/60s/300s/全程）
      着色 ▸（按时间 / 按通道 ▸ 子列表）
      点密度 ▸（高/中/低）
      恢复默认
```

- 菜单组件复用 `shared/Flyout`（现成弹出层）
- 有悬停点时「复制坐标」可用；无数据时「数据」组整体置灰

## 6. 视角与相机

- 预设四视角：俯视（GPS 用）/ 侧视 / 正视 / 等轴（默认）；均带平滑过渡（600ms 缓动，用户偏好自然交互）
- **跟随模式**（T2）：开 → target 每帧 lerp 到最新点，保持当前偏移向量（Foxglove Position 档）；关 → 完全手动
- 自动旋转：展示/演示用（汇报场景）

## 7. 时间游标与时间机器联动（T2）

- 面板底部细时间条：拖动 → 轨迹绘制到该时刻（合并轴二分定位 drawRange），HUD 右下显示相对秒
- 时间机器回放时自动跟随回放时钟（回放 seek 事件已有总线）
- 松手/回放结束回到「跟随最新」

## 8. HUD 布局（防重叠，用户红线）

```
┌──────────────────────────────────────────┐
│ [俯][侧][正][等][⟳]            [跟随][⚙] │ ← 左上视角组；右上模式钮（图标+tooltip）
│                                          │
│                3D 视口                    │
│                                          │
│                              点数/距离小字 │ ← 右下角一行小字（FPS 可选）
└──────────────────────────────────────────┘
        ▁▁▁▁▁ 时间条（T2，仅此一条）▁▁▁▁▁
```

- 无悬浮徽章、无角落堆叠；tooltip 统一 icon+悬停说明（用户偏好）
- 测量结果气泡跟随两点中点，测完可点 × 关闭

## 9. 主题与样式

- 背景/网格/轨迹色带全部映射 CSS 变量，`useSettings()` 主题切换时重建材质颜色
- 轨迹默认色：图例通道色（与 2D 一致的 PALETTE）；时间着色用 turbo 色带（Foxglove/kepler 同款）
- 色弱模式（chartPalette=cbSafe）下时间色带切换 viridis

## 10. 性能预算

| 项 | 预算 | 手段 |
|---|---|---|
| 顶点容量 | 12 万点环形（Float32×2 ≈ 2.9MB，一次性预分配） | 超限环形覆盖；覆盖前沿时间抽稀半采样，旧段自然变稀 |
| 单帧成本 | 新点 append O(k) + 相机静止跳渲染 | 脏检查；`devicePixelRatio` 上限 2 |
| 目标 | 60fps @ 10 万点 | Line 绘制 10 万顶点 GPU <1ms；瓶颈只在 append，O(k) 无风险 |
| 门控 | 面板关闭=零采集零渲染 | `panelActivity.isOpen("plot3d")`（用户红线：关了不许后台跑） |
| dispose | 面板关闭释放 geometry/材质/renderer | ErrorBoundary + useEffect cleanup，姿态面板同模式 |

## 12. 风险与对策

| 风险 | 对策 |
|---|---|
| 三通道时间戳稀疏导致轨迹折线感强 | 文档说明建议同帧打包 xyz；渐隐+点模式可缓解；不做插值（避免编造数据） |
| Line 粗细只有 1px（Windows WebGL linewidth 恒为 1） | T1 接受；T2 提供「短尾迹粗线」可选（Line2 仅小窗口启用，控内存） |
| 极小/极大数量级（经纬度 120.xxx） | 绑定后自动去均值缩放（内部归一到 ±1 视界），HUD 显示真实坐标 |
| three 与姿态面板 chunk 共享后的首帧开销 | 已动态 import 懒加载，无回归风险 |
| 长按测距与拖拽冲突 | 位移 6px 阈值 + 400ms 双条件，实测调优 |

## 13. 验收路径

1. `npm run tauri dev` + demo 源（圆轨迹数据）→ 四视角切换、渐隐、跟随 T2 前手动旋转流畅度
2. 真机 WIT 陀螺：绑 ax/ay/az 看相图；绑位姿积分或 GPS 偏移看航迹
3. 长跑 30 分钟：PerfHud FPS ≥55、内存平稳（环形覆盖生效）
4. 主题切换浅/深各过一遍配色；色弱模式色带
5. 面板关闭重开：无内存泄漏（DevTools heap 对比）
