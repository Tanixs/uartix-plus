## 1. 定位与价值（先读这段）

P71 交付了「采样 → 拟合 → 九参数复制」，但用户拿到系数后只能"盲信"CV 指标。本批补齐校准闭环的**验证侧**与**加计专用侧**：

1. **在线补偿预览**：拟合成功后，实时显示校正后幅值 `r = |W·(x − offset)|` 的迷你时序图——传感器转起来，曲线是一条平稳直线（= 校准好）还是随姿态起伏（= 有残余畸变/温漂），一眼可见。这是"贴进固件前先在本工具里确认有效"的最后一道关。
2. **校正前后对比**：点云一键切换「原始椭球 ↔ 校正后球」，配残差着色（绿=±3% 内 / 黄=±8% / 红=出界），畸变方向和补偿效果直接画在数据上。
3. **加计六面校准向导**：加计有重力先验（g 恒定竖直向下），标准做法是**六面静止采样**（每面 2 秒），比连续翻滚拟合法精度高且流程确定。P71 连续采样法对加计是近似（点云是 6 个离散团簇时锥面拟合矩阵奇异，数学上就走不通），本批给出专用求解器与分步向导。

**仍然不做**：不发校准指令（指令库解锁/CALSW/保存流程不变）；不做温度补偿；不做带倾斜估计的 12 参数六面最小二乘（§4 限制说明）。

## 2. 在线补偿预览

### 2.1 数据流

- **fit 下沉到 store**：P71 中拟合结果存在 Plot3D 组件 state（泵用不到）。本批 `plot3dStore.setCalibFit(fit | null)`：拟合成功推入 store；`clearCalib` / 签名重灌（换绑定/密度/通道）/ `setSink(null)`（面板关闭）时置 null。组件内 fitRef 照旧驱动 HUD 与陈旧标记，store 副本专供泵与 scene。
- **预览环形缓冲**（store 内，preallocated）：`pR: Float32Array(1200)` + `pT: Float64Array(1200)` + `pHead/pLen`——满则覆写最老（ring index，**无任何搬移**）。约 14KB，忽略不计。
- **泵内计算**：校准模式 && `calibFit` 存在时，本批每个新点（与校准采样同源同水位，**不要求正在采样**——预览看的就是日常姿态下的实时补偿效果）计算 `r = ‖W·(x−offset)‖`（W 行主序 9 乘加 + 开方），追加环形缓冲。每点成本 ~15 FLOP，200Hz 泵可忽略。
- **ā 基准**：`FitOk` 新增 `meanR: number`（拟合时校正后幅值均值，原 correctedStats 内部量提升为输出字段，向后兼容附加字段）。

### 2.2 UI（校准 HUD 内）

- 拟合结果区追加：`[补偿预览]` toggle（无 fit 时禁用）。
- 开启后显示迷你残差图：canvas ≈ 224×54，**10Hz 直绘**（interval + 直接 2D context，不走 React state——timebar/悬停同款高频旁路模式）：
  - 横轴 = 最近窗口实际时长（缓冲 1200 点 / 实际到达率自适应），纵轴 = `r/ā`；
  - 参考线：1.0 实线 + ±3% 带绿色 + ±8% 带黄色（与 grade 阈值一致）；数据线 accent 色，越界段红；
  - 图旁实时数字：当前偏差 `((r/ā)−1)%`、窗口内 CV。
- 陈旧联动：拟合后继续采样 → 结果陈旧 → **预览自动挂起**（图冻结灰显 + 「结果基于旧采样」），重新拟合自动恢复。杜绝拿旧系数骗人。

## 3. 校正前后对比（点云显示）

### 3.1 显示模式

HUD 结果区追加 segmented：`显示：[原始] [校正后]`（默认原始；无 fit 禁用）。

- **原始**（现状）：原始点云 + 椭球线框 + 中心标记；**拟合成功后自动叠加残差着色**。
- **校正后**：点云位置改为 `W·(x − offset)`（校正后坐标），线框/中心标记隐藏，显示**参考球线框**（半径 ā）。校准良好时点云应收缩为均匀球壳——这就是"前后对比"。

### 3.2 实现要点（scene.ts）

- `setCalibEllipsoid(fit)` 时**保留 fit 引用**（`calFit`），供显示切换与重锚重写使用；`setCalibDisplay(mode)` 触发一次全量重算（≤20000 点 × 15 FLOP，<1ms）。
- **corrected 模式用独立归一化**（不复用轨迹 anchor/scale）：校正后点云质心平移 + RMS 半径缩放到 ±VIEW_HALF——始终居中，与 raw 锚互不污染；重锚（rewriteCalibNorm/firstData 换锚）按当前显示模式重写。
- **残差着色**：`calGeo` 新增 `aColor` 顶点色属性（Float32Array ×3，PointsMaterial `vertexColors: true`）；着色函数 `color(r/ā)`：|k−1|≤3% 绿 → ≤8% 黄 → 其余红（diverging，直接 CPU 写 RGB，无需 shader 改动）。拟合成功时对存量 20k 点一次性着色；**新追加点即算即色**（setCalibPoints 内 calFit 存在时）；clearCalib / fit 清除 → 恢复 accent 单色。corrected 模式恒 accent 单色（已校正无需着色）。
- 六面模式复用同一着色通道但按**面固定 6 色**（§4）。

## 4. 加计六面校准向导

### 4.1 算法（ellipsoidFit.ts 新增纯函数）

```
fitAccelSix(faces: FaceStats[6], gRef = 1): Accel6Result
FaceStats = { mean: [3], std: [3], n: number }   // faces 顺序固定：+X, −X, +Y, −Y, +Z, −Z（该面朝上静止）
```

- **主轴分量法**（经典六面法）：第 i 轴取 +i/−i 两面在该轴上的均值分量 `a⁺, a⁻`：
  - `offset_i = (a⁺ + a⁻) / 2`
  - `s_i = (a⁺ − a⁻) / (2·gRef)`（原始单位 / g）；`gain_i = 1 / s_i`
  - 校正式 `a' = (a − offset) ∘ gain`，输出 ≈ 1g。
- **质量指标**：各面采集 σ（采集中已算，直接透传）；**三轴尺度一致性** `CV_s = std(s)/mean(s)`（>2% 提示装配/对齐问题）；grade 同款三档。
- **确定性拒绝**（返回可读错误，不输出垃圾系数）：任一面 `n < 30`；任一面 `σ_i > 5%·s̄·gRef`（采集中抖动/未静止）；任一 `|s_i| < ε`（两面均值差≈0，采集顺序错或传感器坏）。
- **已知限制（文档写明）**：主轴分量法假设三轴理想正交、摆放水平；倾斜/非正交误差进入质量指标（各面合成幅值 |mean| 偏差）而不被解算吸收。不做 12 参数带倾斜 LS（复杂度与误用风险不成比例，P74+ 再议）。

### 4.2 状态机（plot3dStore）

```
accel6 = {
  step: -1..5,            // -1 空闲；0..5 = +X..-Z
  collecting: boolean, t0: number,
  sum/sumSq: [3], n: number,        // 累积均值/方差（数值稳定，不存原始点）
  faces: FaceStats[6] | null,
  result: Accel6Ok | null,
}
```

- API：`accel6StartFace()`（当前步开 2.0s 采集窗）/ `accel6Abort()` / `accel6Reset()`；泵在校准模式 && collecting 时累积本批三轴值（stride=1），`now−t0 ≥ 2.0s` 自动结算 mean/std 并 `collecting=false`（UI 轮询 `accel6Snapshot()` 刷新，500ms 同现有）。
- **互斥**：六面采集与椭球连续采样互斥（开启其一先停另一个）；「椭球 ↔ 六面」子模式切换清空对方缓冲（数据语义不同，混用无意义）。
- 面板关闭 `setSink(null)`：accel6 状态整体复位（红线不变）。

### 4.3 UI（校准 HUD 顶部子页）

HUD 标题下加子页切换：`椭球拟合（磁/加通用） | 六面向导（加计专用）`。

```
┌ 六面校准 ─────────────── × ┐
│ 每面朝上静置，点「采集该面」（自动采 2 秒）        │
│ ✓ ＋X 朝上   mean ±σ 已完成                     │
│ ✓ －X 朝上   …                                  │
│ ▶ ＋Y 朝上   [采集该面]  采集中… 1.2s            │
│ ○ －Y 朝上                                      │
│ ○ ＋Z 朝上   ○ －Z 朝上                          │
│ [计算参数]（6 面齐后可用）                        │
│ ── 结果 ──  acc_offset = [...] acc_gain = [...]  │
│ 尺度一致性 CV 0.8%（优）   [复制 C 数组] [清空重来]│
└─────────────────────────────────────────┘
```

- 复制 C：`float acc_offset[3] = {...}; float acc_gain[3] = {...}; // a' = (a - offset) * gain ≈ 1g`。
- 单位：gRef 默认 1（g）；面板可切 `g / m·s⁻²`——仅影响注释与显示（offset 恒 raw 单位、gain 恒 per g），不影响解算。
- 3D 呈现：采集点进同一 calGroup 点云，**按面固定 6 色**着色（当前采集面高亮）；解算成功 → 轴对齐参考椭球线框（rot = I，半轴 = s_i·gRef，复用 setCalibEllipsoid，中心 offset）。

## 6. 边界与对策

| 场景 | 行为 |
|---|---|
| 无 fit 时开预览/切显示 | 控件禁用（≥500 点拟合后才解锁） |
| 预览开启中继续采样 | fit 陈旧 → 预览挂起灰显；重拟合恢复 |
| 预览缓冲满 1200 点 | ring 覆写最老（无搬移、无停顿） |
| 换绑定/密度/通道（签名重灌） | 校准缓冲 + fit + 预览缓冲 + accel6 全清 |
| 六面采集未静止（σ 超标） | 解算拒绝 + 指明第几面，可单面重采 |
| 六面采集顺序错（如两面同为 +X） | sᵢ≈0 或 CV_s 爆表 → 拒绝并提示检查顺序 |
| 椭球与六面互切 | 双方缓冲互清（防混采） |
| 大 offset 传感器 | corrected 独立归一化，显示始终居中 |
| 面板关闭重开 | fit/预览/六面全丢（重采成本低，红线：关了不后台跑） |

## 8. 验收路径（真机）

1. 磁力计流程：采样 → 拟合 → 开「补偿预览」→ 手转传感器：残差曲线应贴 1.0 线小幅抖动（±3% 带内）；单轴靠近铁磁物 → 曲线明显抬升/下凹（验证预览确实在工作）；
2. 「校正后」切换：椭球点云变球、参考球贴合；残差着色红点应集中在翻滚死角；
3. 加计六面：依次六面静置各 2 秒 → 计算参数 → offset/gain 合理、CV_s<2%；故意晃动采集 → σ 超标拒绝；故意重复一面 → 拒绝提示顺序；
4. 复制 C 数组贴固件：水平放置输出 ≈ (0,0,±1)g；
5. 面板关闭重开、切绑定：缓冲/fit/预览全清，无残留（DevTools 内存对比）。
