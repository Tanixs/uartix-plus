## 1. 定位与价值（先读这段）

**椭球校准模式 = 3D 轨迹面板的一个显示模式**（非独立面板），解决两件事：

1. **可视化评估**：磁力计/加计原始三轴在空间中翻滚时，理想分布是球面；存在硬磁偏置（原点偏移）与软磁畸变（球→椭球）。本模式把采样点云 + 拟合出的椭球线框同屏叠加，畸变一目了然（设备侧 WIT CALSW=7 自校准不透明，本工具让用户"看见"校准质量）。
2. **系数产出**：最小二乘拟合输出 **九参数**（硬磁偏置 3 + 软磁对称校正矩阵上三角 6——恰为锥面拟合的 9 个自由度），一键复制 JSON / C 数组，供自研固件/解算算法使用。惯导用户刚需。

**不做**：不发任何校准指令（指令库已有解锁/CALSW/保存流程）；不做在线补偿预览（T+ 批次再议）。

## 2. 核心算法（纯函数模块，零依赖）

### 2.1 拟合（ellipsoidFit.ts）

标准线性最小二乘锥面拟合，**9 参数一次解出**：

```
模型：a·x² + b·y² + c·z² + 2d·xy + 2e·xz + 2f·yz + 2g·x + 2h·y + 2i·z = 1
设计矩阵 D 每行 = [x², y², z², 2xy, 2xz, 2yz, 2x, 2y, 2z]，目标 y⃗ = 1
正规方程 DᵀD·v = Dᵀ1（9×9 对称）→ 高斯消元（部分主元）求解，不引第三方库
```

- **数值条件**：原始 ADC 值动辄数千，直接解 9×9 严重病态。先按点云质心平移 + RMS 缩放归一化，解完再反变换——这是正确性红线，测试覆盖大数值用例。
- **参数还原**：M = [[a,d,e],[d,b,f],[e,f,c]]，b⃗=[g,h,i]；中心 c⃗ = -M⁻¹b⃗；k = 1 + c⃗ᵀMc⃗；对称矩阵特征分解（解析 3×3 或 Jacobi 迭代）→ 半轴 = 1/√(λᵢ/k)，方向 = 特征向量。
- **九参数输出**：
  - `offset = c⃗`（硬磁偏置，3）
  - 软磁校正 `x' = S·Rᵀ·(x - offset)`，S = diag(√(λᵢ/k))（3 增益）、R = 特征向量正交阵（3 旋转自由度）；对称校正矩阵 W = S·Rᵀ 仅 6 个独立量 → **3+6 = 9 参数**；同时给出完整 3×3 W 矩阵（方便固件直接矩阵乘）。
- **退化检测**：λmin ≤ 0 或 k ≤ 0 或任一半轴/均值 > 5 → 拒绝拟合，返回用户可读错误「采样覆盖不足：请让传感器在空间各方向充分翻滚后重试」（点共面/半球时 DᵀD 奇异，高斯消元检测主元≈0 同样拒绝）。

### 2.2 质量指标（同模块）

| 指标 | 含义 | 等级 |
|---|---|---|
| 八象限覆盖 | 以初始质心为原点的 8 个卦限非空计数（0-8） | <6 = 差 |
| 半径变异系数 CV | 归一化后各点半径 std/mean | <3% 优 / <8% 良 / 其余差 |
| RMS 残差 | √mean((|x'|-1)²) | 与 CV 同级展示 |

## 3. 交互与 UI（Plot3D 校准模式）

### 3.1 进入/退出

- 右键菜单新增「模式」组首位：「椭球校准模式」toggle（与轨迹模式互斥）；tr HUD 加一个校准按钮（与跟随钮并排，primary 高亮）。
- 进入条件：三轴已绑齐，否则菜单项禁用 + hint 提示。
- 进入后：轨迹线/渐隐/LOD 全部隐藏（scene 侧 `setCalibMode(true)`，轨迹 drawRange 置 0），切换为**点云渲染**；退出恢复原轨迹（数据未被清动，零重建）。

### 3.2 校准 HUD（左下，替代测量气泡位置；bl 避让规则同 P70）

```
┌ 椭球校准 ──────────────── × ┐
│ 转动传感器使三轴在各方向均匀取向（画 8 字/翻滚全覆盖） │
│ [开始采样] / [停止采样]   采样 N / 20000 点 │
│ 象限覆盖 8/8   CV 2.1%（优）                │
│ [拟合椭球]（≥500 点可用）                    │
│ ── 拟合结果 ──                              │
│ 偏置 offset = [ 123.4, -87.2, 45.0 ]        │
│ 增益 gains  = [ 1.021, 0.987, 1.043 ]       │
│ 软磁矩阵 W（行主序 9 值，含对称冗余）          │
│ [ 1.021, 0.003, -0.012 ]                    │
│ [ 0.003, 0.987, 0.008 ]                     │
│ [ -0.012, 0.008, 1.043 ]                    │
│ [复制 JSON] [复制 C 数组]  [清空重来]         │
└─────────────────────────────────────┘
```

- 采样中：实时点云生长（120ms 泵直写 geometry，渲染节流 200ms）；点数达 20000 上限自动停止并提示。
- 拟合：同步执行（≤2 万点 × 9³，<50ms），结果面板 + 椭球线框（三主平面椭圆 LineLoop，accent 色）+ 中心标记点。
- 复制格式：
  - JSON：`{"offset":[x,y,z],"gains":[x,y,z],"matrix":[[...],[...],[...]],"cv":0.021,"points":12345}`
  - C 数组：`float mag_offset[3] = {...}; float mag_matrix[3][3] = {...};`
- 拟合成功后再采样 → 结果失效标记（陈旧结果变灰 + 「结果基于旧采样」提示）。

### 3.3 采样数据流（plot3dStore 泵复用）

- 校准模式**复用现有三轴绑定与泵管道**（时间水位续传照旧）；泵每 tick 把本批原始值额外追加进 `calibPts` 缓冲（**stride=1 不抽稀**，FIFO 超限整块丢弃最老一半——与 scene 尾窗同款手法，绝无逐点 shift）。
- 缓冲上限 20000 点（3×f64 ≈ 480KB，内存安全）；面板关闭泵停 → 校准缓冲与结果随实例丢弃（红线：关了不许后台跑；重采成本低，可接受）。
- 回放/实时源无区别（都从 plotStore 消费）；录制中的实时源为推荐用法。

## 4. 逐文件改动

### 4.1 `src/features/plot3d/ellipsoidFit.ts`（新增，纯函数零依赖）

- `fitEllipsoid(pts: number[][]): FitResult` —— FitResult = `{ ok: true, offset, gains, matrix, axes, rot, cv, rms } | { ok: false, reason: string }`
- `octantCoverage(pts): number`、`grade(cv): "优"|"良"|"差"`
- 内部：3×3 对称 Jacobi 特征分解、9×9 高斯消元（部分主元）、归一化/反变换。全部可单测。

### 4.2 `plot3dStore.ts`

- `Plot3DSettings` + `calibMode: boolean`（持久化，默认 false；与 autoRotate/follow 互斥联动——校准模式锁定视角无意义，进入时自动全关）。
- 泵内：calibMode 时批次追加进 `calibPts`（含水位续传语义一致）；`startCalibCapture()/stopCalibCapture()/clearCalib()`、`calibSnapshot()`（UI 低频读：点数/象限/是否采样中）。
- 拟合动作放 UI 侧直调 `fitEllipsoid(calibPts)`（store 不持结果，结果存 Plot3D 组件 state——低频数据可进 state）。

### 4.3 `scene.ts`

- 新 API：`setCalibMode(on)` / `setCalibPoints(f32: Float32Array, n: number) | null` / `setCalibEllipsoid(fit: FitResult | null)`。
- 渲染：独立 `calibGroup`（Points + 3×LineLoop 椭圆 + 中心点 sprite），进校准模式时轨迹组 visible=false、drawRange=0（不销毁缓冲，退出即恢复）；点云归一化沿用现有 anchor/scale 流水线（大坐标安全）。
- 椭圆线框：由 fit 的 center/axes/rot 生成三主平面参数椭圆各 128 段，进入/重拟合时重建（低频，成本可忽略）。

### 4.4 `Plot3D.tsx`

- 校准 HUD 面板（§3.2）、tr 按钮、右键菜单「模式」组；拟合按钮 → `fitEllipsoid(plot3dStore.calibPts())`；结果 state + 复制按钮（navigator.clipboard 先例 copyHover）。

### 4.5 Operator 包兼容（小项）

- `operatorPkg.ts`：`OperatorPayload` + `plot3d?: Plot3DSettings`；导出时读 `vs.plot3d.settings` localStorage 打包（只带绑定/显示偏好，**不带 calibMode**——校准模式是操作态，操作员端进包后默认轨迹模式）。
- `operatorStore.ts`：apply 时 `p.plot3d` 写回 localStorage（key 同名，loadSettings 自动生效）；`validatePkg` 规整该段（缺省跳过）。

### 4.6 `theme.css`

- `.p3d-calib` 面板（复用 .p3d-measure 同构：bg-panel/border/mono 字体）、按钮行、结果表格样式。

## 5. 边界与对策

| 场景 | 行为 |
|---|---|
| 点共面 / 半球采样 | DᵀD 奇异或 λ≤0 → 拒绝拟合 + 可读错误（不输出垃圾系数） |
| 原始值数量级大（ADC 数千） | 拟合前归一化（§2.1 红线），测试覆盖 1e4 量级用例 |
| 加计校准（重力方向） | 同一算法适用（点云分布在球面）；文档提示加计需六面静止采样，本工具的连续采样法对加计是近似——建议优先磁力计场景 |
| 采样中切换绑定/密度 | 签名变化触发重灌；校准缓冲**清空重来**（数据源变了混采无意义）+ 提示 |
| 校准中开关 follow/autoRotate | 进入校准模式强制全关；退出不恢复（用户手动） |
| 拟合成功后继续采样 | 旧结果标记陈旧（灰显），需重新点击拟合 |
| 面板关闭重开 | 校准缓冲/结果丢弃，calibMode 设置保留（进入即空面板提示开始采样） |
| clipboard 不可用 | toast 提示（copyHover 同款路径） |

## 7. 验收路径（真机）

1. `npm run tauri dev` + WIT 磁力计原始三轴绑 XYZ → 进校准模式 → 缓慢翻滚/画 8 字 → 点云渐满、象限 8/8；
2. 拟合：椭球线框贴合点云、偏置/增益数值合理、CV<3%；复制 C 数组到固件验证；
