## 1. 核心洞察（本批唯一关键决策，先读这段）

**回放联动 = 零重建，纯游标。**

依据（已核实源码）：
- 回放引擎（session.rs play_loop）以**原始时间戳**经 `send_frames` 单点重灌 → framesBus → plotStore 正常追加（P42 架构决策「回放=Rust 虚拟源与 demo 同构」的既有红利）；
- plotStore 合并轴恒有序（buildAlignedFull k 路归并按 min(t) 取点）；
- 3D 场景双层 LOD 缓冲是 **append-only 且按时间升序**（tT/oT 单调不减）。

推论：
| 回放动作 | 3D 侧行为 | 成本 |
|---|---|---|
| 正常回放推进 | 现有水位 lastT 增量追加照常工作（重灌点 ts ≤ lastT 自动跳过） | 0 改动 |
| seek **向前**（B>A） | 重灌段 (A,B] 被水位正常消费；游标前移 | 0 重建 |
| seek **向后**（B<A） | 场景已含 [首…A] 全部几何 → **只需 drawRange 截断到 B** | O(log n) 二分 |
| 回放结束 | 游标=null 恢复全量显示；水位=源末尾（重复点自动跳过） | 0 |

因此本批唯一新原语：**TimeCursor（相对秒 | null）**，同时服务三个场景：①非回放手动拖时间条（scrub 查看历史段）②回放自动跟随 ③游标截断处的渐隐锚定。**绝不做任何轨迹重建**。

## 2. TimeCursor 语义（单点机制）

```
cursor = null        → 跟随最新：drawRange 全量、uNow=lastT、最新点标记在末点
cursor = T(相对秒)   → 截断显示：尾窗二分找末个 ≤T 的下标 ct、全景 co；
                       tailGeo/ovGeo.setDrawRange(0, ct/co)；
                       uNow=T（渐隐窗口锚定游标，轨迹头部亮尾部暗随游标移动）；
                       最新点标记移到截断点（游标处"当前时刻"位置）；
                       pick 搜索范围同步截断（count 用 ct/co）
```

三态来源与优先级（pump 每 120ms 统一裁决，单入口下发）：

| 态 | 来源 | cursor 值 |
|---|---|---|
| 回放中（playing/paused） | sessionStore.firstTs + posMs | (firstTs+posMs−timeOrigin)/1000，clamp 到源范围 |
| 手动 scrub | 用户拖时间条（非回放） | scrub 值，**松手保留**（查看历史意图明确）；「回到最新」或双击时间条清除 |
| 都没有 | — | null |

互斥：回放开始自动清 scrub；scrub 开始（非回放）时若在回放则走 seek 而非 scrub（见 §4）。

## 3. 逐文件改动

### 3.1 plot3dStore.ts
- `st` 增 `lastReplayTs: number`（回放游标去抖：变动 <5ms 不下发）。
- 泵尾（数据批次下发后）追加游标裁决：
  - `isReplaying()` → cursor=replayRelSec，`lastReplayTs` 跟随（**检测回退仅影响 cursor 值，不触发重灌**）；
  - 否则若 `scrubSec != null` → cursor=scrubSec；
  - 否则 cursor=null。
- Sink 签名扩展：`(b, reloaded, cursorSec: number | null)`——数据与游标同入口同序，避免 applyBatch 重设 drawRange 后被旧游标覆盖的时序问题。applyBatch 内部：先追加/重置，末尾若 cursorSec!=null 调内部 applyCursor 覆盖。
- 新增 `setScrub(sec: number | null)`（内存态，不持久化、不进 snapshot——纯泵侧裁决输入，UI 直调 scene + 此处）。
- 测试注入口 `_setSessionForTest({ playing, replayRelSec })`（与 `_setProviderForTest` 同模式，解耦 sessionStore）。

### 3.2 scene.ts
- 新 API `setTimeCursor(relSec: number | null)`（§2 语义；`lowerBoundLe` 二分纯函数，文件内可测）。
- applyBatch 第三参 `cursorSec`，末尾调用 setTimeCursor（null 时恢复全量）。
- 新 API `setFollow(on)`：
  - 渲染循环 `controls.update()` 后：`target.lerp(锚点, 0.15)`（平滑），camera.position 加同款 delta（**保持视角偏移向量**，Foxglove Position 档语义）；锚点 = 截断点（有游标）或末点；
  - 开启时取消进行中的 tween；与 autoRotate 互斥（store 层开关时联动，scene 不管）；
  - follow 平移本身置 needsRender（有位移才渲染，静止零负载不变）。

### 3.3 Plot3D.tsx
- **底部时间条**（新 HUD 元素，面板最底独立一条，高 ~16px）：
  - 结构：细轨道 + 已看段高亮 + 菱形游标 + 左右端相对秒刻度（0s / fmtTickSec 全程）；拖动时游标上方浮小气泡显示当前值。
  - 数据范围：`fullAlignedRaw()` 首末 O(1) 读（plot 10Hz 快照已驱动重渲染，无需新增订阅）。
  - 交互（pointer capture，防 mouseup 丢失）：
    - 非回放：拖动 → `scene.setTimeCursor(rel)` + `plot3dStore.setScrub(rel)`（ref 直调，60Hz 不进 state）；松手游标保留；双击时间条或「回到最新」→ setScrub(null)+setTimeCursor(null)。
    - 回放中：拖动 → `sessionStore.seek(ratio, 当前速度)`——**真时间机器 seek**，hex 环复位+全面板同步倒带，3D 经重灌+游标自动跟随（§1 机制）。
  - 回放进度显示：useEffect 内 `sessionStore.subscribe` 直写 DOM（fill 宽度/游标位置），**不进 React state**（10Hz 高频红线）。
- **跟随模式按钮**（右上 HUD，图标+tooltip，用户偏好规范）：toggle `settings.follow`（新设置项，持久化，默认 false）；开启时联动关 autoRotate（反之亦然）。
- 右键菜单：「视图」组加「跟随模式（锁定最新点）」；「数据」组加「回到最新（清除时间游标）」。
- br 统计行：scrub/回放时追加 `· t = 12.4s`（游标相对秒，fmtTickSec 同款格式：34s / 5m / 1.2h，本地 3 行小函数，不做跨文件抽象）。
- 布局防重叠（用户红线）：时间条 `bottom:0` 独立条；测量气泡 bl 上移至时间条上方（`bottom: 24px`）；br 统计行同步上移。

## 4. 边界与对策

| 场景 | 行为 |
|---|---|
| 回放中 3D 面板刚打开 | 水位 −Inf 全量消费（含旧 pass 重复点，同值同位叠加无害）→ 游标=posTs |
| 三轴未绑定 | 不消费不下发游标；绑定后正常 |
| scrub 中实时数据继续到 | 照常追加（被 drawRange 隐藏），松手「回到最新」即见 |
| 回放结束（stopped/ended） | cursor=null 全量恢复；水位已=源末尾，重灌重复点永不二次消费 |
| 游标处拾取/测量 | pick 截断范围内搜索；已放置的测量线不受游标影响（仅重灌/清空才清） |
| follow + 用户旋转 | 旋转只改朝向，target 仍被拉回锚点——符合「锁定」语义；平移（右键拖）被 follow 每帧校正，提示文案写明「跟随中平移暂失效」 |
| session 时钟 ≠ plotStore 时钟 | 不可能：帧 ts 同源（pipeline ingest）；防御性 clamp 游标到 [0, 末尾] |
| 演示源/实时源 | 无回放态，时间条纯 scrub 用 |

## 5. 测试（plot3dStore.test.ts 追加，vitest）

1. 回放态泵下发 cursor（mock session：playing + replayRelSec）；
2. seek 向后：cursor 值回退，批次仍只含新增（不重灌不重复）；
3. seek 向前越段：水位跳过重复段、cursor=新位置；
4. 回放结束：cursor=null；
5. scrub 态：applyBatch 第三参=scrub 值；setScrub(null) 恢复；
6. lowerBoundLe 纯函数：边界（空/首/尾/重复 ts）。

scene 侧（WebGL）不做自动化，靠真机验收。

## 6. 验收路径（真机）

1. `npm run tauri dev` → 录制或打开会话（含三轴数据）→ 开 3D 轨迹绑定三轴；
2. 回放 1×：轨迹随回放生长；拖进度条向后 → 轨迹**瞬间截断**到目标时刻（无闪重建）；向前 → 续长；
3. 暂停：游标停住；结束回放 → 全轨迹恢复；
4. 非回放拖 3D 底部时间条：轨迹截断 + 渐隐锚定游标 + 右下显示 `t=…`；松手保留；「回到最新」恢复；
5. 跟随模式：实时源下 target 平滑锁定最新点，旋转视角不脱靶；关闭恢复自由；
6. 测量气泡不与时间条重叠；悬停拾取在截断外无命中。
